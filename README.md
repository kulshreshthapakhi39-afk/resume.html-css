# Student Internship Resume

A modern, responsive resume template built with HTML, CSS, and JavaScript, designed specifically for students applying for internships.

## Features

- **Responsive Design**: Looks great on desktop, tablet, and mobile devices
- **Modern Styling**: Clean, professional appearance with subtle animations
- **Interactive Elements**: Hover effects, smooth scrolling, and print functionality
- **Print-Friendly**: Optimized for printing with proper page breaks
- **Customizable**: Easy to modify content and styling

## Sections Included

- Header with profile picture and contact information
- Objective statement
- Education background
- Skills (organized by category)
- Projects with descriptions and links
- Work experience and volunteer roles
- Certifications and awards

## How to Use

1. **Replace Placeholder Content**: Update all the placeholder text in `index.html` with your actual information.

2. **Add Your Profile Picture**: Replace `profile.jpg` with your own photo. The image should be square (1:1 aspect ratio) for best results.

3. **Customize Styling**: Modify `style.css` to change colors, fonts, or layout as needed.

4. **Update Links**: Replace placeholder GitHub links and social media URLs with your actual profiles.

5. **Personalize**: Add or remove sections based on your background and the internship requirements.

## File Structure

```
resume/
├── index.html      # Main HTML structure
├── style.css       # Styling and responsive design
├── script.js       # Interactive functionality
└── profile.jpg     # Your profile picture (add this file)
```

## Browser Support

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## Printing

Click the "Print Resume" button or use your browser's print function (Ctrl+P / Cmd+P) to generate a PDF version suitable for submission.

## Customization Tips

- **Colors**: The primary color is blue (#007bff). Change this in `style.css` to match your personal brand.
- **Fonts**: Currently using Arial. Consider using Google Fonts for a more unique look.
- **Layout**: The design uses CSS Grid for skills and Flexbox for other elements.
- **Animations**: JavaScript adds subtle animations. Disable them if you prefer a static resume.
